## TMDB Enrichment
- Input your personal [TMDB API key](https://www.themoviedb.org/settings/api) and click save first. Then toggle it on.
### Modules
- Disable "Artwork", "Episodes", and "Season Posters".
	- Note: If you are using my AIOMetadata setup I recommend turning these OFF since our setup already pulls them more accurately for us.
## MDBList Ratings
- Input your personal MDBList API key and click save first. Then toggle it on.
## Connected Services (Optional)
- Link your Torbox account under accounts. Useful if you want to see your library from Torbox *(i.e. You add a torrent for a new episode/movie on your account, that scrapers from AIOStreams do not have yet, and use Nuvio to view the torrent without having to wait).*
	- Enable "Resolve playable links".
	- Enable "Prepare links".
