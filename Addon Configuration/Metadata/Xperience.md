- Visit [Xperience](https://xperience-app.com), and sign up for an account
- Head to Profiles and create a new profile. 
	- Create a name for your profile and select which preset you would like to use (Everyday mix is recommended).
---
## Setup
### Integrations
- Add API keys for MDBList and TMDB. Click verify for both before proceeding.
	- If you are using Simkl you can also connect it here (optional).
### AI Recommendations
- Insert your Gemini API key and disable "AI-powered search".
### Search
- Leave only "Include Xperience in Nuvio Search" toggled on.
### Discover
- Keep "Show the built-in Movies and Series browse catalogs" toggled on.
### Posters
- Put your Posters+ and/or BetterPosters URL and click verify before proceeding.
	- Enabled all toggles at the bottom of posters section.
### Preferences
- Change Time zone to your Time zone.
- Change Series season & episode source to The TVDB only (matches Simkl)
- Customize how you would like your metadata by excluding genres and movies/shows you've seen already. (Change the filters to your liking).
### Anime
- Change Anime episode numbering to "Seasonal"
- Keep Anime stream ID to "IMDb"
---
## Home Rows
- Your preset should have already installed some catalogs here but you are free to add or remove any you want.
---
## Collections
- Preset collections can be added if wanted in this section.
---
## Finalize
- Link your Nuvio account by signing in.
- Push to Nuvio
	- The addon should automatically install itself to your Nuvio. *You can also choose which profile to send this configuration too if you are handling multiple profiles.*
