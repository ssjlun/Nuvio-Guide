## Create and Import Configuration
- On the lefthand side, first go to the Configuration tab to create a configuration. 
	- Enter a password in order it to create your config. *(I recommend using something simple and make it the same as your AIOStreams config)*
- Still on the configuration tab, go down to where you see import configuration and use my file you downloaded to import my settings.
## Integrations
- On the lefthand side, click the Integrations tab and paste in your API keys for TMDb, TVDb, MDBList and Gemini. 
	- Test your keys and make sure they all have green check marks.
## Catalogs
- On the lefthand menu, click the Catalogs tab and click the little logo for Simkl (small s) to link your Simkl account.
	- You can then import your watchlists from simkl.
## Art Providers
- On the lefthand menu, click the Art Providers tab and paste your Posters+ URL in the bottom of the Art Providers tab, where it says Poster URL Pattern—replace existing URL if there is one.
## Save Your Configuration & Install
- Go back to the Configuration tab on the left and click save configuration.
	- You should now see a personal UUID code. Save this, as this is your 'username'.
- You should see a manifest json URL generate after saving your config, this is what will be installed to Nuvio. Click the Copy button.
- Go to Nuvio>Settings>General>Content&Discovery>Addons. Paste the manifest json URL and click add addon. You should now see a new add-on named AIOMetadata.

**MAKE SURE AIOMETADATA ADDON IS YOUR VERY FIRST ADDON, ON THE TOP OF THE LIST!!! (USE THE ARROW)**
