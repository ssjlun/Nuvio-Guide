## Create and Import Configuration
-  On the lefthand menu, first go to Save & Install to create a configuration. Enter a password in order to create your config (save this too). Skip the install to Stremio menu.
- Still on the configuration tab, go down to where you see import and use my file you downloaded to import my settings/filters. Click on Import Config.
## Integrations
- On the lefthand side, click the Services tab and select the settings icon for TorBox. Put in your API key obtained from Torbox and click save. (make sure it is toggled on). 
- Still on the services tab, click metadata on the top menu and input your TMDB read access token and API key, as well as your TVDB API key.
## Save Your Configuration & Install
- Go back to the Configuration tab on the left and click save configuration.
	- You should now see a personal UUID code. Save this, as this is your 'username'.
- You should see a manifest json URL generate after saving your config, this is what will be installed to Nuvio. Click the Copy button.
- Go to Nuvio>Settings>General>Content&Discovery>Addons. Paste the manifest json URL and click add addon. You should now see a new add-on named AIOStreams.
