# TorBox
This will be our debrid service used. Debrid services are high-speed downloaders that fetch files from hosters and torrents, then stream them to you via a secure, high-bandwidth connection.
## Create an Account and Retrieve API
- Create an account for [TorBox](https://torbox.app) and sign up for the $3/month subscription (Essential Plan).
	- *Credit Card Recommended.* 
- Click the dropdown menu on the top right, go to Settings and scroll down until you see Copy API Key—no need to apply.

# TMDB
TMDB (The Movie Database) acts as the foundation for your metadata, pulling in high-quality artwork, episode details, and cast information.
## Create Account and Retrieve API
- Create a free account at [TMDB](https://www.themoviedb.org)
- Head to your Account Settings and select the API link from the left sidebar
- Request an API key and select Yes, this is for personal use. 
	- Fill out the form using random information—it really does not matter, you just need the key.
- Copy the API key or Read Access Token depending on what is needed.

---
# TVDB (For Advanced Setup Only)
TVDB (The TV Database) acts as an alternative metadata and episode-numbering database source used to look up and organize TV shows and anime.
## Create Account and Retrieve API
- Create a free account at [TVDB](https://www.thetvdb.com/home)
- Click on your account dropdown menu on the top right and head to your Dashboard. 
	- Once on the dashboard, on the left sidebar click account, then API keys.
- Visit their API page linked and Request an API key and fill out the form using random information—it really does not matter, you just need the key.
- Head back over to Dashboard>Account>API keys to copy your API key.

---
# MDBList
MDBList aggregates rating scores from multiple platforms so you can see audience and critic scores directly on the metadata pages.
## Create Account and Retrieve API
- Register for a free account at [MDBList](https://mdblist.com)
- Go to your account preferences and scroll down to API Access to generate a free API key—no need to apply.
	- Make sure you copy only the API key string itself, not the full URL.

# Gemini (Optional, for recommendations)
Whether you choose AIOMetadata or Xperience as your metadata aggregator, you have the option to use Gemini AI to read your watch history and provide recommendations.
- Sign up for a google account if you have not done so, and head to [Google AI Studio](https://aistudio.google.com/api-keys)
- Click Create API key on the top right to generate your key.
	- You should now be able to copy your key.
